# راهنمای دیپلوی ربات (Webhook روی Render)

## مرحله ۱: آپلود روی گیت‌هاب
1. یک ریپازیتوری جدید بساز (می‌تونه Private باشه)
2. فایل‌های `app.py`، `requirements.txt`، `Procfile` رو داخلش push کن
3. **توکن ربات رو داخل هیچ‌کدوم از این فایل‌ها ننویس** — قراره از Environment Variable استفاده کنیم

## مرحله ۲: ساخت سرویس روی Render
1. وارد https://render.com شو و با گیت‌هاب لاگین کن
2. روی **New +** بزن و **Web Service** رو انتخاب کن
3. ریپازیتوری‌ای که ساختی رو انتخاب کن
4. تنظیمات:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn app:app`
   - **Instance Type:** Free برای تست کافیه

## مرحله ۳: تنظیم Environment Variables
تو بخش **Environment** سرویس، این دو مقدار رو اضافه کن:
- `BOT_TOKEN` = توکنی که از BotFather گرفتی
- `WEBHOOK_SECRET` = یک رشته دلخواه و تصادفی (مثلاً `mySecret_98x7Klm`) — این فقط برای امنیت بیشتره تا کسی نتونه با حدس زدن مسیر webhook برات پیام جعلی بفرسته

## مرحله ۴: Deploy
روی **Create Web Service** بزن. Render شروع به build و اجرا می‌کنه.
وقتی deploy موفق بود، برنامه خودش به‌صورت خودکار (توی تابع `setup_webhook`) آدرس webhook رو
با استفاده از آدرس عمومی Render ثبت می‌کنه. تو لاگ‌های Render باید ببینی:
```
نتیجه ثبت webhook: {'ok': True, 'result': True, ...}
```

## مرحله ۵: تست
تو تلگرام برو سراغ رباتت و `/start` بزن. باید منو بیاد.

## نکات مهم
- **پلن رایگان Render** بعد از ~15 دقیقه بی‌فعالیتی، سرویس رو Sleep می‌کنه؛
  اولین پیام بعد از خواب رفتن، چند ثانیه طول می‌کشه تا بیدار بشه.
  همچنین موقع Sleep/Restart، حافظه‌ی موقت کاربران (لیست عکس‌های در حال جمع‌آوری) پاک می‌شه.
- اگه می‌خوای این محدودیت نباشه، باید پلن پولی Render رو انتخاب کنی یا از یک دیتابیس
  خارجی (مثل Redis) برای نگه داشتن state استفاده کنیم — بگو تا اضافه‌ش کنم.
- اگه توکن قبلاً جای دیگه‌ای (چت، گیت‌هاب عمومی) به اشتراک گذاشته شده، حتماً از
  BotFather با `/revoke` یکی جدید بگیر قبل از اینکه اینجا به‌عنوان Environment Variable بذاریش.
